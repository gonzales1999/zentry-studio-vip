# Zentry Reference Subtitles + Animations

Paquete recreado a partir del video de referencia proporcionado.

Contenido:
- 27 presets de animación tipográfica.
- 8 estilos visuales de subtítulos/títulos observados en el video.
- MP4 individual de cada preset.
- Código Remotion reutilizable.

Instalación:
```bash
npm install
npm start
```

Uso:
```tsx
<ReferenceTextAnimation
  text="ZENTRY MOTION"
  animation="slide-up"
  unit="words"
/>
```

Carpetas:
- `src/animations/`
- `src/subtitles/`
- `previews/animations/`
- `previews/subtitles/`

Nota:
La recreación es visual y funcional, no una copia del código del producto mostrado en el video.
El nombre del preset 27 aparece parcialmente cortado en el material; se normalizó como `Letras en ascenso`.
